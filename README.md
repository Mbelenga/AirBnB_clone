# AirBnB Clone

This project is a simple recreation of some of the core features of the AirBnB website. It is built as part of my software engineering learning journey to practice Python, object-oriented programming, and web development concepts.

## Features

* Create and manage users
* Create and manage places
* Manage reviews
* Manage amenities
* Store and retrieve project data
* Command-line interface for interacting with the application

## Technologies

* Python
* Object-Oriented Programming
* JSON
* Git and GitHub
